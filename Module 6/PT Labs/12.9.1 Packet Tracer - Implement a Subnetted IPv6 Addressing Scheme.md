## Lab Summary

In this lab, I will assign subnet to the LANs and configure both routers and PCs with IPv6 addresses. I will determine the appropriate IPv6 subnetting and addressing scheme. Then apply the configuration to the routers and PCs. After completing the setup, I will test IPv6 connectivity.

## Reflection Questions

### 1. What did you do in this lab?

For this lab, I was provided with IPv6 subnet 2001:db8:acad:00c8::/64 as my starting point. I will need to create four additional subnets for each network. After completing the subnet table, I will configure the IPv6 address on the routers and PCs. Finally,  I will test connectivity to ensure all configurations were done correctly.

### 2. What did you learn?
I learned how to complete a subnetting table for IPv6 addresses and the use of CLI for the routers. Using the CLI to configure the IPv6 address to the routers for each interfaces. I learn that the command ipv6 unicast-routing is used for routers to enable IPv6 routing. Without using ipv6 unicast-routing command the router will not forward IPv6 packets between interfaces, even if the interface are configured with IPv6 addresses. 

### 3. What did you struggle with or not fully understand?
My biggest struggle was forgetting ipv6 unicast-routing command. When I set all four PC to auto config IPv6 it wouldn't give the PC an IPv6 address. That's when I forgot to put the ipv6 unicast-routing command on the routers.
