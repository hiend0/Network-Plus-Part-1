### 2. What did you learn?
Layer 3 switching allows a switch to send data between different VLANs, like a router. This means devices in different VLANs can communicate with each other without needing a separate router. By using Switch Virtual Interfaces (SVIs), a Layer 3 switch handles inter-VLAN routing efficiently, making the network faster and easier to manage.
