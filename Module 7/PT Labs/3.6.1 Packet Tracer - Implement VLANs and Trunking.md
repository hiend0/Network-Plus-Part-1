## Lab Summary

In this lab, I will learn how to implement VLANs and trunking for a company preparing to deploy a new set of switches in a branch office. I will configure both static and dynamic trunking. Static trunking involves manually setting a switch port as a trunk using specific commands, while dynamic trunking uses the Dynamic Trunking Protocol (DTP) to automatically negotiate trunk links between switches.

---

## Reflection Questions

### 1. What did you do in this lab?
In this lab, I will implement VLAN and trunking configurations. I will set up VLANs on all three switches based on the provided VLAN table. After that, I will assign access ports to their respective VLANs and configure voice VLAN ports. Additionally, I will implement both static and dynamic trunking.

### 2. What did you learn?
I learned that trunking is used to carry multiple VLANs accross a single physical link between switches or between switches and routers. VLAN is used to divide a physical network into separate broadcast domains. Together, VLANs and trunking provide a secure and organized way to manage large networks.
