## Reflection Questions

### 1. What did you do in this lab?

During this lab, I had to identify the problems within the network from incorrect VLAN and inter-VLAN routing configuration. Commands I used to locate the problems are show ip interface brief, show interface g0/1.30, show interface g0/1.30, and show interface trunk. Once problems are identify I will then implement the solutions and verify network connectivity.

### 2. What did you learn?
I learned how to use show commands to check if the network is set up correctly. For example, the command show interface g0/1.10 revealed that while the physical interface g0/1 was up, the subinterface g0/1.10 was administratively down. After checking all configuration settings using these show commands, I simply compared them against the requirements listed in the Addressing Table to make sure everything was correct.

## Documentation Table

|     Problems     |     Solutions     |
|------------------|-------------------|
| PC3 Default Gate was incorrectly configured | Change Default Gateway from 172.17.10.1 to 172.17.30.1 |
| G0/1 on S1 is configured as an access port instead of trunk port | Use command switchport mode trunk to change the interface | 
| Subinterface G0/1.10 is administratively down | Use command no shutdown for this subinterface G0/1.10 |
| Subinterface VLAN are incorrectly configured for G0/1.10 and G0/1.30 | Use command no encapsulation dot1q to remove the incorrect configuration. Then use command encapsulation dot1q vlan_number to reenter correct IP Address for these subinterfaces |
